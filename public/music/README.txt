THƯ MỤC NHẠC THÁNH CA CỦA BẠN
============================

Từ phiên bản v7, app KHÔNG còn nhạc tích hợp sẵn: trình phát Thánh Ca
CHỈ phát các file nhạc trong thư mục này (định dạng .mp3, .ogg
hoặc .m4a).

CÁCH THÊM / XÓA NHẠC (từ v80): qua TRANG QUẢN LÝ /admin
- Mở địa chỉ của nhà thờ thêm /admin ở cuối (ví dụ
  http://localhost:3000/admin), nhập khóa quản trị, rồi dùng thẻ
  "Nhạc thánh ca": chọn file nhạc để thêm, hoặc bấm Xóa ở từng bài.
- Thêm hoặc xóa xong, người chơi mở lại panel Thánh Ca là thấy
  danh sách mới.
(Cách cũ chép tay file vào thư mục này vẫn dùng được.)

- Mở panel Thánh Ca bằng nút Thánh Ca trên thanh điều khiển phía dưới,
  hoặc đi tới GÓC CA ĐOÀN trong nhà thờ (hành lang bên trái phía bàn
  thờ, có đàn piano) rồi bấm mở.
- Chưa có file nào thì panel hiện danh sách trống.
- Đặt tên file dễ nhớ, ví dụ: "Ave Maria.mp3" — tên file (bỏ phần mở
  rộng) sẽ hiện trong trình phát nhạc của app.
- LƯU Ý BẢN QUYỀN: chỉ dùng những file nhạc bạn có quyền sử dụng. Nếu
  đăng web công khai, hãy dùng nhạc của chính bạn, nhạc được phép chia
  sẻ, hoặc giai điệu thuộc phạm vi công cộng.
